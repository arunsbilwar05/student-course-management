# Student Course Management Frontend

A React JS application for managing student and course information with reusable components, forms, routing, hooks, and Context API.

## Features
- React Router for page navigation
- Reusable UI components
- Props and state management
- Student and course forms with event handling
- List rendering using keys
- Bootstrap-based responsive design
- useState() and useEffect() hook usage
- Context API for shared data

## Project structure
- `src/components` — reusable cards and forms
- `src/context` — global context store
- `src/pages` — route-based views
- `src/App.jsx` — app routing and provider setup
- `src/main.jsx` — app entry point
- `src/index.css` — custom styles
